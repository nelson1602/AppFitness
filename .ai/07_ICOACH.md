# Purpose

This document defines the official specification of the iCoach Engine.

The iCoach Engine is the core intelligence of AppFitness.

For public v1, it transforms self-entered physical assessments, nutrition data, workout history, recovery inputs, user preferences, available equipment, schedule, and goals into deterministic, explainable, and evidence-based fitness guidance.

The existing medical inputs and rules are retained as dormant implementation only. Public v1 must not collect them, surface them, or feed them into iCoach. Reactivation requires a separate approved ADR and legal, privacy, consent, security, and release review.

Every recommendation generated by iCoach must be reproducible, traceable, scientifically supported, and versioned.

No recommendation may rely solely on generative AI.

---

# Core Mission

iCoach exists to help users pursue fitness and wellness goals safely through deterministic decision making.

Its responsibilities include:

• Physical assessment analysis

• User-declared physical limitation analysis

• Nutrition planning

• Workout planning

• Progress evaluation

• Recovery evaluation

• Goal tracking

• Habit reinforcement

• Conservative fitness-safety guardrails

• Recommendation generation

# Explainability

Every recommendation must answer:

Why?

Which inputs?

Which formulas?

Which rule?

Which version?

What changed?

No recommendation should behave as a black box.

Explanations are presentation data. Domain outputs must expose stable structured
reason codes and values so Spanish and English renderings do not alter engine
behavior or recommendation identity.

# AI Instructions

Every AI agent working on AppFitness must treat the iCoach Engine as the most critical subsystem.

Protect determinism.

Protect explainability.

Protect user safety.

Protect historical integrity.

When uncertainty exists, prefer conservative recommendations.

Never generate coaching behavior that cannot be fully explained through deterministic business rules.
